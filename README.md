
# Blutdruck Tracker PWA

## Funktionen
- Blutdruck speichern
- Puls speichern
- Verlauf anzeigen
- Diagramm
- Offline nutzbar
- iPhone Homescreen Installation

## Start lokal
Einfach mit einem lokalen Webserver öffnen.

Beispiel:
python -m http.server 8000

Danach:
http://localhost:8000

## iPhone Installation
Safari öffnen → Teilen → Zum Home-Bildschirm
